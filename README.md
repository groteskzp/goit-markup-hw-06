# WebStudio

Landing page for **WebStudio**, a digital studio that offers effective solutions for business.

This repository is the final HTML/CSS homework of the GoIT Markup module (`goit-markup-hw-06`). The page is a single-file landing layout built with semantic HTML5 and CSS3.

## Live demo

[https://groteskzp.github.io/goit-markup-hw-06/](https://groteskzp.github.io/goit-markup-hw-06/)

## Features

- Header with the WebStudio logo, navigation (Studio, Portfolio, Contacts), email (`info@devstudio.com`), and phone (`+11 (000) 111-11-11`)
- Mobile menu with the same navigation, contact links, and social icons
- Hero section with the heading “Effective Solutions for Your Business” and an **Order Service** button
- Values section (Our Features): Strategy, Punctuality, Diligence, and Technologies
- Team section with four members (photo, name, role, and social links)
- Portfolio section with six projects (Banking App, Cashless Payment, Meditation App, Taxi Service, Screen Illustrations, Online Courses) and a hover overlay
- Footer with logo, short description, social media links, and an email subscribe form
- Contact modal form (name, phone, email, comment, Privacy Policy checkbox, and Send)
- Responsive layout for mobile, tablet (`768px`), and desktop (`1158px`)
- Adaptive and retina images (`<picture>`, `srcset`, `2x`) and an SVG icon sprite
- Hover and focus transitions on links, buttons, and cards

## Tech stack

- HTML5
- CSS3 (Flexbox, media queries, transitions)
- SVG sprite
- Google Fonts: [Roboto](https://fonts.google.com/specimen/Roboto) and [Raleway](https://fonts.google.com/specimen/Raleway)
- [modern-normalize](https://github.com/sindresorhus/modern-normalize)

## Getting started

Clone the repository and open the page in a browser. No build step or package manager is required.

```bash
git clone https://github.com/groteskzp/goit-markup-hw-06.git
cd goit-markup-hw-06
```

Open `index.html` in your browser.
